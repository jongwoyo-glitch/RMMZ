# 역사적 무기·방어구 사전 (확장판)

> 프로젝트 내 정의된 무기/방어구 타입별로 실존했던 역사적 무기·방어구의 이름, 기원, 역사적 유래와 용례를 정리한 참고 문서.
> 게임 내 장비 이름 작명 및 세계관 설정 시 참고용으로 사용한다.
> 2차 조사(2026-05-01): 인도·동남아·아프리카·메소아메리카·동아시아 세분화·유럽 마이너·중앙아시아/캅카스 추가 완료.
> 3차 게임 참조(2026-05-01): 디아블로·엘든링·마비노기·소울류 시리즈 참조, 역사적 무기 16종 추가.
