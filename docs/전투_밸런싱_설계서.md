# 전투 밸런싱 설계서 — 무기·방어구 전투 특성

> SRPG 전투 시스템의 밸런싱 원칙, 피격 판정, 무기·방어구별 전투 특성 프리셋을 정의한다.
> 기존 SRPG_Core의 반격/명중/전투 시스템과 RMMZ 네이티브 스탯을 기반으로 설계.
> 작성일: 2026-05-02

## 1. 핵심 설계 원칙

### 1.1 유효 레벨 체계

캐릭터의 전투력을 **유효 레벨** 하나로 환산한다.

```
유효 레벨 = 실제 레벨 + 장비 보정 + 스킬 보정
```

#### 7티어 장비 체계 (만렙 99, 성장 x20)

| 티어 | 코드 | 적정 레벨 | 무기ATK(직검) | 기본ATK | 총ATK | 기본HP | 비고 |
|------|------|----------|-------------|--------|------|-------|------|
| T1 공통기본 | Common I | Lv 1~14 | 11 | 34 | 45 | 170 | 초반 범용 군수품 |
| T2 공통개량 | Common II | Lv 15~28 | 25 | 75 | 100 | 375 | 중급 범용 무기 |
| T3 공통고급 | Common III | Lv 29~42 | 39 | 115 | 154 | 575 | 고급 범용 무기 |
| T4 인종기본 | Faction I | Lv 43~56 | 53 | 156 | 209 | 780 | 인종 문화권 특화 |
| T5 인종정예 | Faction II | Lv 57~70 | 66 | 197 | 263 | 985 | 인종 정예 무기 |
| T6 이종족기본 | Exotic I | Lv 71~84 | 80 | 237 | 317 | 1185 | 이종족 제작 무기 |
| T7 이종족정예 | Exotic II | Lv 85~99 | 94 | 280 | 374 | 1400 | 이종족 정예 무기 |
| 전설 | Legendary | — | 별도 | — | — | — | 티어 외 별도 트랙 |

> **무기ATK 산출**: 기본ATK ÷ 0.62 × 0.38 × 0.55 (장비38%중 무기55%)
> 위 표의 무기ATK은 한손직검(배율 1.00) 기준. 무기 유형별 배율(0.70~1.72)을 곱하여 최종값 산출.
> 각 티어의 기본ATK = 해당 레벨 구간 중앙값의 캐릭터 ATK. (선형 보간: Lv1=15, Lv99=300)
> HTK 검증: 기본HP ÷ (기본ATK + 무기ATK) ≈ 3.73 → DEF/PDR 적용 시 ~5.0 수렴.
> 99레벨 / 7티어 = 각 ~14레벨 균등 배분. 티어간 ATK 증가폭 12~14 균등.

만렙 기준 전투력 비율: **레벨 62% / 장비 38%** (만렙 99, 성장 배율 x20)

### 1.2 전투 밴드 (유효 레벨 차이별 전투 성격)

| 유효 레벨 차 | 밴드 | 전투 성격 |
|-------------|------|-----------|
| 0 ~ 5 | 전략 영역 | 스탯 차이 미미. 지형·협공·진형이 승패 결정. |
| 6 ~ 15 | 도전 영역 | 스탯 열세 체감. 완벽한 전략으로 역전 가능. |
| 16+ | 성장 영역 | 전략으로 뒤집기 거의 불가. 성장 체감 구간. |

### 1.3 죽창력 유지 원칙

**동등 조건 기준 HTK = 5. 이 비율을 전 구간에서 유지한다.**

- 같은 레벨, 같은 티어 장비, 같은 갑옷 유형끼리 싸우면 **서로 5대에 죽는다**
- 5대 vs 5대 — 먼저 5대를 넣는 쪽이 이기는 것이 기본 전투
- 레벨이 올라도, 장비 티어가 올라도 동등 조건 HTK 5는 변하지 않는다
- HP와 ATK의 성장 비율을 항상 5:1로 유지하여 이를 보장한다
- 상성·장비·전술에 따라 이 기준점에서 **±1~3**이 움직인다

| 시점 | 기본 ATK | 기본 HP | 비율(HP/ATK) | 기준 HTK |
|------|---------|--------|-------------|---------|
| Lv 1 | 15 | 75 | 5.0 | **5** |
| Lv 25 | 85 | 425 | 5.0 | **5** |
| Lv 50 | 158 | 790 | 5.0 | **5** |
| Lv 75 | 230 | 1150 | 5.0 | **5** |
| Lv 99 | 300 | 1500 | 5.0 | **5** |

> **만렙: 99. 성장 배율: x20. 기본 ATK 15 → 300.**
> 장비 비중 ~38% 포함 시 풀빌드 ATK ~484, HP ~2420.
> 레벨당 ATK 증가: ~2.9. 매 레벨업마다 확실한 성장 체감.

**HTK 변동 요인 (기준 5에서의 ±):**

| 요인 | HTK 변화 | 예시 |
|------|---------|------|
| 무기 상성 유리 | -1 (→4대) | 둔기 vs 중갑 |
| 무기 상성 불리 | +1~2 (→6~7대) | 단검 vs 중갑 |
| 갑옷 유형 강세 | -1~2 (→3~4대) | 대형무기 vs 의복 |
| 갑옷 유형 약세 | +1~2 (→6~7대) | 단궁 vs 중갑 |
| 협공(2인 이상) | 실질 -1~2 | 반격 분산, 방어 붕괴 |
| 측면/후방 공격 | -1 (명중·크리 보정) | 측면: 명중 1.5배 |
| 지형 고저차 우위 | -0.5~1 | 고지에서 공격 |
| 장비 티어 차이 | 유효 레벨 차로 환산 | T7 vs T1 = 유효 Lv차 ~84 |

→ 전투의 본질: "동등하면 5대 싸움. 유리함을 쌓아서 4대, 3대로 줄이는 것이 전략."
→ 수적 우위의 핵심: 3명이 1명을 때리면 5대 중 2~3대를 분담. 사실상 2턴 컷.

## 2. 피격 판정 순서

공격이 발생하면 아래 순서로 판정한다.

```
1. 명중 판정 (HIT vs EVA/MEV)
   └→ 빗나감(MISS) → 종료

2. 방어 판정 (GRD — 방패 소지 시)
   └→ 막힘(BLOCK) → 데미지 대폭 감소 (GRD 효과율 적용) → 3으로

3. 흘림 적용 (PDR / MDR)
   └→ 물리: 최종 데미지 × PDR (중갑일수록 PDR 낮음 = 덜 아픔)
   └→ 마법: 최종 데미지 × MDR (의복/로브일수록 MDR 낮음 = 덜 아픔)

4. 치명타 판정 (CRI vs CEV)
   └→ 치명타 시 데미지 배율 적용

5. 최종 데미지 확정

6. 반격 판정 (조건 충족 시)
```

### 2.1 반격 규칙

기존 SRPG_Core의 `canCounter()` 기반, 아래 원칙을 적용:

| 조건 | 반격 발생 여부 |
|------|--------------|
| 근접 vs 근접, 서로 사거리 도달 | O (100% — CNT로 제어) |
| 근접 vs 근접, 방어자 사거리 미달 | **X** (일방 피격) |
| 원거리/마법 → 근접 | X (기본 반격 불가) |
| 원거리/마법 → 근접 + 특수 스킬 | O (스킬별 CNT 보정) |

**핵심 상호작용:**
- 창(사거리 2)이 검(사거리 1)을 공격 → 반격 없음 (일방 피격)
- 검이 창에 인접 후 공격 → 서로 사거리 도달 → 반격 발생
- 궁수/마법사가 근접 유닛 공격 → 기본 반격 없음
- 검사가 "화살 튕기기" 패시브 보유 → 원거리 공격에도 반격 발동 (CNT 확률)

### 2.2 방어(GRD) 재정의

RMMZ 기본: GRD = "방어 커맨드 효과율"
→ SRPG 재정의: GRD = **피격 시 자동 방어 발동률** (방패 기반)

- 방패 장비 시 GRD 수치에 따라 확률적으로 데미지 대폭 감소
- 방패 미장비 시 GRD = 0 → 방어 판정 스킵
- 발동 시 데미지 50~70% 감소 (방패 등급에 따라)

## 4. 무기 유형별 전투 특성 프리셋

> 모든 보정값은 **해당 무기 유형 장비 시 기본 적용되는 트레잇 보정**.
> 개별 무기는 이 프리셋 위에 미세 조정을 추가한다.
> EVA/CRI/HIT 보정은 xparam 가감(±절대값). PDR 영향은 관통/절단 등 원소 타입으로 처리.
> 사거리(reach)는 기존 WeaponTypeRanges 파라미터 유지.

### 범례

- **사거리**: 기존 SRPG 타일 범위 (WeaponTypeRanges 기준)
- **사격 모드**: melee(근접) / direct(직사) / arc(곡사)
- **반격 상호**: 이 무기가 반격을 받는/하는 조건에 대한 특이사항
- **EVA 보정**: 이 무기 사용 시 사용자 회피율 가감
- **CRI 보정**: 치명타율 가감
- **HIT 보정**: 명중률 가감
- **비고**: 전투 특성 요약

### 근접 무기 4군 역할 변별 원칙

> 근접 무기의 가장 큰 변별력은 **"누구를/무엇을 상대할 때 강한가"**이다.
> 이 원칙은 한손/양손/대형 모두 동일하게 적용된다.

| 무기군 | 핵심 역할 | 대의복 | 대경갑 | 대중갑 | 대엄폐물 |
|--------|----------|--------|--------|--------|---------|
| **직검** | 범용 스탠다드 | 기준 | 기준 | 기준 | 기준 |
| **곡도** | 경장 킬러 | **강세** | **강세** | 약세 | 기준 |
| **둔기** | 중갑 킬러 | 기준 | 기준 | **강세** | 기준 |
| **도끼** | 엄폐물 파괴 | 기준 | 기준 | 기준 | **강세** |

**구현 메커니즘:**
- **곡도**: 경장(의복·경갑) 착용 대상에게 피해 배율 증가 (×1.3). 절단 원소가 경장 약점.
- **둔기**: 중갑 착용 대상에게 DEF 관통 비율 증가 (DEF 40~50% 무시). 타격 원소가 중갑 약점.
- **도끼**: 파괴 가능 사물(바리케이드, 벽, 방패진 등)에 피해 배율 대폭 증가 (×1.8~2.0).
- **직검**: 특별한 보정 없음. 어떤 상대에게도 기준 HTK 유지. 범용성 자체가 강점.

**편성 의미:**
- 적 구성이 중갑 위주 → 둔기 편성 우선
- 적 구성이 경장 위주 → 곡도 편성 우선
- 성벽·바리케이드 돌파 필요 → 도끼 편성 필수
- 적 구성 불명 / 혼합 → 직검이 가장 안전

## 5. 방어구 유형별 방호 특성 프리셋

> 방어구 특성은 **착용 시 기본 적용되는 트레잇 보정**.
> DEF/MDF는 개별 방어구 수치로, 아래는 유형 공통 특수 보정만 기술.
> PDR/MDR은 1.0 기준. 낮을수록 해당 피해를 적게 받는다.
> **CRI(치명타율)**: 방어구에 부여하지 않음. 개인 스킬 전용.
> **TGR(타겟률)**: 방어구에 부여하지 않음. 스킬 전용. AI 타겟은 AI 알고리즘+역할 프리셋으로 결정.
> **GRD(방어 효과)**: 방패 전용. 몸통·부위 방어구에 GRD 없음. 스킬로 방패 없이 발동 가능.

### 5.1 몸통 방어구

| armorType | 방어구 유형 | EVA 보정 | PDR | MDR | 마법 사용 | 이동력 패널티 | 비고 |
|-----------|-----------|---------|-----|-----|----------|-------------|------|
| 1 | 일반 의복 | 0 | 1.00 | 1.00 | 가능 | 없음 | **순수 기준점.** 방어 보정 없음. 더 나빠지지도 않음 |
| 2 | 경갑 | 0 | 0.92 | 1.00 | 가능 | 없거나 적음 | 물리 8% 감소. 기동성 유지. 범용 기동형 |
| 3 | 중갑 | -0.05 | 0.78 | 1.00 | **불가** | -1 | 물리 22% 감소. 회피 불리. 마법 불가. 둔기에 ×1.5 취약 |

**설계 의도:**
- 의복 = 기준점. 보정 없음. 더 나빠질 수 없음.
- 경갑 = 의복 + 물리 방어 약간. 패널티 없음. 가장 범용.
- 중갑 = 물리 대폭 감소 + 마법 불가 + 이동력 패널티 + 회피 불리. 명확한 트레이드오프.
- MDR은 방어구가 아닌 개별 스킬·버프·원소 내성으로 처리.

### 5.2 방패

|-----------|----------|---------|---------|------|
| 4 | 소형 방패 | +0.15 | +0.03 | 버클러. 경량. 패링 느낌. 단병기와 궁합 |

| 6 | 대형 방패 | +0.35 | -0.05 | 전신 방패. 최고 방어, 회피 감소 |

**GRD 방어 발동 시 효과 (shieldBlock 노트태그):**
- 소형 방패: 데미지 50% 감소 (패링)
- 중형 방패: 데미지 60% 감소
- 대형 방패: 데미지 70% 감소 (완전 차단에 가까움)

**GRD는 방패 전용 장비 스탯.** 스킬(패링, 무기 방어 등)로 방패 없이도 발동 가능.

## 6. HTK 기준표 (동렙·동티어 기준)

> **HTK = Hits to Kill**. 해당 공격자가 해당 방어자를 일반공격으로 처치하는 데 필요한 타격 횟수.
> 동일 레벨, 동일 티어 장비 기준. 스킬·버프·지형 보정 미적용.
> **기준점: 동등 조건 HTK = 5. 이 표는 공격자-방어자 조합별 편차를 보여준다.**
> **이 표는 레벨·티어에 무관하게 동일하다** (죽창력 유지 원칙).

### 6.2 HTK 읽는 법

**기준점: 경갑 열 = 5가 기본.** 여기서 벗어나는 칸이 상성이다.

- **경갑 5** = 기준점. 동등 조건 5대 교환의 원칙 그대로.
- **의복 3~4** = 방호 없는 대상. 대형무기는 2대. 보호 실패 = 즉각 위험.
- **중갑 5~6** = 기준보다 +1~2. 물리 탱킹 확인. 협공 필요.
- **중갑 3~4 (둔기/마법)** = 상성 역전. 둔기는 DEF 관통, 마법은 DEF 자체가 무의미.
- **원거리 HTK가 높은 이유** = 반격 면역의 대가. 안전한 만큼 느리다.
- **단검·권갑 HTK가 높은 이유** = 낮은 단발 화력. 회피·CRI·반격으로 실질 DPS 보상.

### 6.3 HTK 불변 원칙과 체감 변화

**HTK 자체는 변하지 않는다.** Lv 1이든 Lv 50이든 동등 조건이면 5대.

하지만 체감은 달라진다:

- **스킬 계층이 추가됨**: 고레벨에서는 일반공격보다 스킬 비중이 커짐. 스킬은 HTK 밖의 별도 데미지 체계.
- **장비 티어 격차**: T3 vs T1이면 유효 레벨 차 ~8. "도전 영역"에서 싸우는 것과 같음.
- **버프·디버프 누적**: 고레벨에서 가용한 버프가 많아지면서 실질 HTK가 변동.
- **수적 우위 극대화**: 고레벨에서 AP·스킬 체계가 성숙하면 협공 효율이 올라감.

→ HTK 5는 "일반공격 기준 상수". 실전에서의 킬타임은 스킬·버프·전술로 조절.
→ 이것이 "성장은 느껴지지만 죽창력은 유지된다"의 핵심.

## 6.5 HTK 난이도 곡선 — "5대는 목표지, 보장이 아니다"

> **저레벨에서 HTK=5는 공짜. 고레벨에서 HTK=5는 실력.**
> 레벨이 올라갈수록 적의 빌드가 단단해지면서, 최적화 없이는 HTK가 밀려난다.
> HTK=5를 유지하려면 점점 더 많은 전술적 요소를 맞춰야 한다.

### 레벨 구간별 HTK=5 달성 조건

| 레벨 구간 | 아무것도 안 맞추면 HTK | HTK=5 달성에 필요한 것 | 체감 난이도 |
|----------|---------------------|---------------------|-----------|
| Lv 1~20 | 5~6 | 적절한 무기만 있으면 충분 | 튜토리얼 |
| Lv 20~40 | 6~7 | 무기 상성 + 기본 스킬 조합 | 입문 전략 |
| Lv 40~60 | 7~8 | 상성 + 스킬 + 장비 티어 매칭 + 기본 협공 | 본격 전략전 |
| Lv 60~80 | 8~9 | 위 + 디버프/버프 + 지형 활용 + 진형 | 숙련 영역 |
| Lv 80~99 | 9~10 | 위 + 풀 민맥싱 + 장판/함정 + 완벽한 협공 | 고인물 영역 |

### HTK 달성 수준별 플레이어 체감

| 달성 HTK | 의미 | 전투 체감 |
|---------|------|----------|
| **3~4** | 민맥싱 끝판왕 | 적이 녹는다. 고인물의 보상. |
| **5** | 설계 기준점 | 빡빡하지만 공정한 전투. 이것이 목표. |
| **6~7** | 약간 부족 | 싸울 수 있지만 턴이 늘어짐. 원군·변수에 취약. |
| **8~10** | 최적화 미달 | 질질 끌리는 소모전. 사실상 다른 전략이 필요하다는 신호. |

### 설계 원칙

- **같은 숫자, 다른 의미**: 초반 HTK 5 = "그냥 됨." 후반 HTK 5 = "다 맞춰서 겨우 됨."
- **숫자가 아닌 복잡성으로 난이도 상승**: 적의 스탯이 올라서 어려운 게 아니라, 맞춰야 할 퍼즐이 늘어서 어려움.
- **고인물 보상**: 모든 걸 완벽히 맞추면 HTK 3~4. 이것이 민맥싱의 대가.
- **실패의 친절함**: HTK 8이 되면 "이기기 어렵다"지 "죽는다"가 아님. 퇴각·재편성 여지 있음.

## 6.6 전략적 하극상 — %HP 데미지 체계

> 레벨 격차가 극심할 때, 일반 ATK로는 데미지가 의미 없다.
> 그러나 **%HP 기반 데미지**는 레벨과 무관하게 적의 체력을 깎는다.
> 이것이 "레벨 1의 죽창" — 전략적 선택과 준비로 만드는 하극상.

### %HP 데미지 원천 (계획)

| 유형 | 예시 | %HP 효과 | 비고 |
|------|------|---------|------|
| 환경 장판 | 독늪, 용암, 가시밭 | 턴당 최대HP 5~10% | 유인·밀치기로 강제 진입 |
| 설치 함정 | 화약통, 함정, 낙석 | 1회 최대HP 15~25% | 사전 배치 필요. 소모품 |
| 환경 파괴 | 다리 붕괴, 화공, 수공 | 최대HP 20~40% + 상태이상 | 맵 오브젝트 상호작용 |
| 디버프 스킬 | 독, 출혈, 저주 | 턴당 최대HP 3~8% | 스킬 슬롯 투자 필요 |
| 특수 소모품 | 맹독병, 화염유 | 1회 최대HP 10~15% | 제작·구매 자원 소모 |

### 설계 원칙

- **일반 ATK와 %HP는 다른 축**: ATK는 레벨·장비에 비례. %HP는 레벨 무관.
- **%HP는 준비 비용이 크다**: 함정 설치, 소모품 제작, 지형 유인 등 사전 투자 필요.
- **수(水) 오행 친화**: %HP 기반 전략은 수 오행의 핵심 플레이 스타일.
- **고인물 플레이**: Lv1 부대가 함정+독+화공으로 만렙을 잡는 것은 가능하지만, 극도의 전술이 필요.
- **스택 제한**: %HP 효과는 동시 적용 상한선 존재 (밸런스 파괴 방지).

## 7. 전투 특성 프리셋 — RMMZ 구현 방안

### 7.1 권장 구현: 노트태그 + 플러그인 자동 적용

무기 개별 노트태그에 프리셋 키를 지정하면, 플러그인이 해당 유형의 기본 보정을 자동 적용:

```
<weaponProfile: shortBlade>
```

플러그인 내부에서 프리셋 테이블 참조:
```javascript
const WEAPON_PROFILES = {
    shortBlade:  { eva: 0.08, cri: 0.06, hit: 0.03 },   // 단검
    straightSwd: { eva: 0.03, cri: 0.02, hit: 0.02 },   // 한손직검
    curvedSwd:   { eva: 0.05, cri: 0.04, hit: 0.00 },   // 한손곡도
    // ... 27개 전체
};
```

**장점:** 프리셋 수치를 한 곳에서 수정하면 해당 유형 전체에 반영.
개별 무기에서 추가 미세 조정 가능 (`<bonusEva:+0.02>` 등).

### 7.2 방어구도 동일 구조

```
<armorProfile: heavyArmor>
```

```javascript
const ARMOR_PROFILES = {
    cloth:      { eva: 0, pdr: 1.00, mdr: 1.00 },  // 기준점. 보정 없음
    lightArmor: { eva: 0, pdr: 0.92, mdr: 1.00 },  // 물리 8% 감소
    heavyArmor: { eva:-0.05, pdr: 0.78, mdr: 1.00, elementRate: { 11: 1.5 } },
    // 방패, 부위 등 — TGR/GRD/CRI는 방어구에 부여하지 않음
};
```
