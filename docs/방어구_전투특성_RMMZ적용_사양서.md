# 방어구 전투 특성 — RMMZ 적용 사양서

> 전투 밸런싱 설계서의 방어구 전투 특성을 RMMZ Studio DB에 실제 반영하기 위한 구체적 사양.
> 장신구(반지/목걸이/팔찌)는 개별 아이템 효과이므로 프리셋 없음. 이 문서는 몸통·방패·부위 방어구만 다룬다.
> 작성일: 2026-05-02 / 개정: 2026-05-02

---

## 0. 설계 원칙 — 방어구가 담당하지 않는 것

| 스탯 | 담당 | 비고 |
|------|------|------|
| CRI (치명타율) | **개인 스킬 전용** | 방어구에 CRI 보정 없음 |
| TGR (타겟률) | **스킬 전용** | 전투 중 스킬로 오버라이드. AI 타겟 결정은 AI 알고리즘 + 역할 프리셋 |
| GRD (방어 효과) | **방패 전용** | 몸통·부위 방어구에 GRD 없음. 스킬로 방패 없이 발동 가능 |

## 1. RMMZ 스탯 매핑 — 방어구용

### 1.1 xparam (추가 능력치) — 특성 코드 22

| dataId | 이름 | 용도 | 기본값 |
|--------|------|------|--------|
| 0 | HIT (명중률) | 장갑 착용 시 무기 파지 안정성 | 0 |
| 1 | EVA (회피율) | 갑옷 무게에 따른 회피 보정 | 0 |
| 3 | CEV (치명타 회피) | 투구 착용 시 치명타 피해 경감 | 0 |

**RMMZ Studio 설정**: 방어구 편집 → 특성(Traits) → 추가 능력치(xparam)

### 1.2 sparam (특수 능력치) — 특성 코드 23

| dataId | 이름 | 용도 | 기본값 |
|--------|------|------|--------|
| 1 | GRD (방어 효과) | 방패 자동 방어 발동률 | 0% (방패만 사용) |
| 6 | PDR (물리 데미지율) | 물리 피해 배율. 낮을수록 유리 | 100% |
| 7 | MDR (마법 데미지율) | 마법 피해 배율. 낮을수록 유리 | 100% |

**RMMZ Studio 설정**: 방어구 편집 → 특성(Traits) → 특수 능력치(sparam)

> **주의**: PDR/MDR은 RMMZ에서 100%가 기본이며, 수치를 낮추면 피해 감소.

### 1.3 원소 내성 (Element Rate) — 특성 코드 11

| 설정 | 용도 |
|------|------|
| 속성 유효도 → 타격(11) | 둔기 계열 피해 배율 |
| 속성 유효도 → 관통(12) | 창/쇠뇌/궁 피해 배율 |
| 속성 유효도 → 절단(13) | 직검/곡도/도끼 피해 배율 |

**RMMZ Studio 설정**: 방어구 편집 → 특성(Traits) → 속성 유효도(Element Rate)

## 2. 몸통 방어구 (armorType 1~3)

### 2.1 설계 원칙

| 유형 | 역할 | 물리 방어 | 마법 사용 | 이동력 패널티 | 은신 |
|------|------|----------|----------|-------------|------|
| 의복 | 기준점. 방어 능력 없음 | 없음 (기본값) | 가능 | 없음 | 기본 |
| 경갑 | 기동 + 약간의 방호 | 약간 | 가능 | 없거나 적음 | 없거나 약간 |
| 중갑 | 물리 탱킹 특화 | 강함 | **불가** (물리 스킬은 가능) | 있음 | 없거나 패널티 |

**핵심 철학**:
- 의복은 스탠다드. 더 나빠질 수 없는 기준점 그 자체. 보정이 아예 없음.
- 경갑은 의복에서 "물리 방어를 약간 올린 대신 특별한 패널티 없음". 가장 범용.
- 중갑은 물리 방어를 크게 올린 대신, 마법 사용 불가 + 이동력 패널티 + 회피 불리. 명확한 트레이드오프.

### 2.2 몸통 방어구별 RMMZ Studio 설정

#### 일반 의복 (armorType: 1)

| 항목 | 설정 |
|------|------|
| EVA 보정 | 0% (설정 불필요 — 기본값) |
| PDR | 100% (설정 불필요 — 기본값) |
| MDR | 100% (설정 불필요 — 기본값) |
| 원소 내성 | 설정 불필요 (기준 100%) |
| 노트태그 | `<armorClass:cloth>` |
| 비고 | **순수 기준점.** 방어 보정 없음. 더 나빠지지도 않음. DEF/MDF는 개별 아이템 기본 수치로만 |

#### 경갑 (armorType: 2)

| 항목 | 설정 |
|------|------|
| EVA 보정 | 0% (설정 불필요 — 이동성 유지) |
| PDR | 92% (특성 → sparam → 물리 데미지율 92%) |
| MDR | 100% (설정 불필요 — 기본값) |
| 원소 내성 | 설정 불필요 (기준 100%) |
| 노트태그 | `<armorClass:light>` |
| 비고 | 물리 피해 8% 감소. 마법·이동·회피 패널티 없음. 범용 기동형 |

#### 중갑 (armorType: 3)

| 항목 | 설정 |
|------|------|
| EVA 보정 | -5% (특성 → xparam → 회피율 -0.05) |
| PDR | 78% (특성 → sparam → 물리 데미지율 78%) |
| MDR | 100% (설정 불필요 — 기본값) |
| 원소 내성 | **타격(11) = 150%** (특성 → 속성 유효도 → 타격 150%) |
| 노트태그 | `<armorClass:heavy><magicSeal:true><movePenalty:1>` |
| 비고 | 물리 22% 감소. 회피 -5%. 둔기 계열 ×1.5 취약. **마법 사용 불가**. 이동력 -1 |

### 2.3 몸통 방어구 상성 요약

| 공격 측 | vs 의복 | vs 경갑 | vs 중갑 |
|---------|---------|---------|---------|
| 물리 일반 (절단/관통) | ×1.00 (기준) | ×0.92 (약간 감소) | ×0.78 (대폭 감소) |
| 둔기 (타격 원소) | ×1.00 | ×0.92 | ×0.78 × 1.5 = **×1.17** (상성 역전) |
| 곡도 (curved 노트태그) | ×1.00 × 1.5 = **×1.50** | ×0.92 × 1.5 = **×1.38** | ×0.78 × 0.7 = **×0.55** |
| 마법 일반 | ×1.00 | ×1.00 | ×1.00 |

> 의복은 모든 공격에 ×1.00. 기준점.
> 경갑은 물리만 ×0.92로 소폭 감소. 마법은 기준.
> 중갑은 물리 ×0.78로 대폭 감소, 둔기에 상성 역전, 곡도에 극강. 마법은 기준 (MDR 100%).
> 마법에 대한 취약/강세는 방어구가 아닌 개별 스킬·버프·원소 내성으로 처리.

### 2.4 유틸리티 제약 정리

| 유틸리티 | 의복 | 경갑 | 중갑 |
|---------|------|------|------|
| 마법 사용 | O | O | **X** (물리 스킬은 가능) |
| 이동력 패널티 | 없음 | 없거나 적음 | -1 (노트태그) |
| 은신 보정 | 기본 | 없거나 약간 | 없거나 패널티 |
| 환경 저항 | 없음 (개별 아이템) | 없음 (개별 아이템) | 없음 (개별 아이템) |

> 환경 저항(한랭/사막 등)은 갑옷 클래스가 아닌 **개별 아이템의 특수 스탯**으로 처리.
> 은신은 추후 스텔스 시스템 설계 시 구체화. 현재는 방향성만 기록.

## 3. 방패 (armorType 4~6)

### 3.1 설계 원칙

방패는 **GRD(방어 효과)** 의 유일한 장비 소스.
GRD 발동 시 물리 공격을 확률적으로 차단. 스킬을 통해 방패 없이도 GRD 발동 가능 (패링, 무기 방어 등).

| 유형 | GRD 발동률 | 발동 시 감소율 | EVA 보정 | 편성 의도 |
|------|-----------|-------------|---------|----------|
| 소형 방패(버클러) | 15% | 50% | +3% | 경쾌한 패링. 단병기·도적과 궁합 |
| 중형 방패 | 25% | 60% | 0% | 표준 방패. 공방 균형 |
| 대형 방패 | 35% | 70% | -5% | 전신 방패. 최고 방어, 회피 감소. 탱커 전용 |

> **GRD 감소율 차등**: `<shieldBlock:N>` 노트태그로 처리. 플러그인이 GRD 발동 시 이 값을 읽어 피해 경감 비율 적용.
> **방패 없이 GRD**: 스킬(패링, 무기 방어 등)이 전투 중 임시 GRD 보정을 부여. 방패 유무와 무관하게 발동 가능.

### 3.2 방패별 RMMZ Studio 설정

#### 소형 방패 / 버클러 (armorType: 4)

| 항목 | 설정 |
|------|------|
| GRD 보정 | +15% (특성 → sparam → 방어 효과 +0.15) |
| EVA 보정 | +3% (특성 → xparam → 회피율 +0.03) |
| 노트태그 | `<shieldBlock:50>` |
| 비고 | 패링 느낌. 경량. 단병기·도적과 궁합. 발동 시 피해 50% 감소 |

#### 중형 방패 (armorType: 5)

| 항목 | 설정 |
|------|------|
| GRD 보정 | +25% (특성 → sparam → 방어 효과 +0.25) |
| EVA 보정 | 0% (설정 불필요) |
| 노트태그 | `<shieldBlock:60>` |
| 비고 | 표준 방패. 공방 균형. 발동 시 피해 60% 감소 |

#### 대형 방패 (armorType: 6)

| 항목 | 설정 |
|------|------|
| GRD 보정 | +35% (특성 → sparam → 방어 효과 +0.35) |
| EVA 보정 | -5% (특성 → xparam → 회피율 -0.05) |
| 노트태그 | `<shieldBlock:70>` |
| 비고 | 전신 방패. 최고 방어. 회피 감소. 발동 시 피해 70% 감소. 탱커 전용 |

### 3.3 방패 + 몸통 조합 효과

| 조합 | 물리 방어 구조 | 특징 |
|------|-------------|------|
| 중갑 + 대형 방패 | PDR 78% + GRD 35%(70% 감소) | 물리 최강 탱킹. 회피 -14%. 마법·둔기가 천적 |
| 경갑 + 중형 방패 | PDR 92% + GRD 25%(60% 감소) | 균형형 방어. 기동성 유지 |
| 의복 + 소형 방패 | PDR 100% + GRD 15%(50% 감소) | 최소 물리 방어. 패링으로 가끔 생존 |
| 경갑 + 없음 | PDR 92% 단독 | 양손무기·궁병. 공격 집중 |
| 의복 + 없음 | PDR 100% 단독 | 마법사. 방어 전무. 후방 배치 필수 |

## 4. 부위 방어구 (armorType 10~12)

### 4.1 설계 원칙

투구·신발·장갑은 의복/경갑/중갑 분류를 따르지 않는다. 각 부위 내에서 **티어별 소재 진보**(가죽→사슬→판금)로 DEF/MDF 기본 수치가 올라가며, 아래의 xparam/sparam 보정은 **유형 공통 기본값**.

CRI는 방어구에 부여하지 않는다 (개인 스킬 전용).

### 4.2 투구 (armorType: 10)

| 항목 | 설정 범위 | 비고 |
|------|----------|------|
| EVA 보정 | -1% ~ -3% | 티어↑ = 무거움. 판금 투구는 시야·기동성 제한 |
| PDR 보정 | 97% ~ 95% | 머리 방호. 티어↑ = 물리 감소 증가 |
| CEV 보정 | +2% ~ +5% | **치명타 피해 경감**. 투구의 고유 역할 |
| 노트태그 | `<armorSlot:helm>` | 부위 식별용 |

**티어별 예시**:

| 티어 | EVA | PDR | CEV | 예시 |
|------|-----|-----|-----|------|
| T1 (가죽) | -1% | 98% | +2% | 가죽 모자, 가죽 투구 |
| T2 (사슬) | -2% | 96% | +3% | 사슬 두건, 사슬 투구 |
| T3 (판금) | -3% | 95% | +5% | 판금 투구, 풀 헬름 |

#### RMMZ Studio 기본 설정 (armorType 10 공통)

| 항목 | 설정 |
|------|------|
| EVA 보정 | -2% (특성 → xparam → 회피율 -0.02) — 기준값. 개별 ±1% 조정 |
| PDR 보정 | 97% (특성 → sparam → 물리 데미지율 97%) — 기준값 |
| CEV 보정 | +3% (특성 → xparam → 치명타 회피 +0.03) — 기준값 |
| 노트태그 | `<armorSlot:helm>` |

### 4.3 신발 (armorType: 11)

| 항목 | 설정 범위 | 비고 |
|------|----------|------|
| EVA 보정 | +3% ~ -1% | 경화 = 회피↑, 판금 = 회피↓ |
| PDR 보정 | 100% ~ 98% | 하체 방호 소폭 |
| AGI | 개별 아이템 기본 수치로 처리 | 이동력은 SRPG 플러그인 노트태그 별도 |
| 노트태그 | `<armorSlot:boots>` | 부위 식별용 |

**티어별 예시**:

| 티어 | EVA | PDR | 예시 |
|------|-----|-----|------|
| T1 (가죽) | +2% | 100% | 가죽 장화, 여행자의 신발 |
| T2 (사슬) | +1% | 99% | 사슬 각반, 경량 그리브 |
| T3 (판금) | -1% | 98% | 판금 그리브, 철제 각반 |

#### RMMZ Studio 기본 설정 (armorType 11 공통)

| 항목 | 설정 |
|------|------|
| EVA 보정 | +1% (특성 → xparam → 회피율 +0.01) — 기준값 |
| PDR 보정 | 99% (특성 → sparam → 물리 데미지율 99%) — 기준값 |
| 노트태그 | `<armorSlot:boots>` |

### 4.4 장갑 (armorType: 12)

| 항목 | 설정 범위 | 비고 |
|------|----------|------|
| HIT 보정 | +1% ~ +2% | 무기 파지 안정성. 티어↑ = 미세 증가 |
| PDR 보정 | 100% ~ 97% | 손·팔 방호 소폭 |
| 노트태그 | `<armorSlot:gloves>` | 부위 식별용 |

> CRI는 장갑에 부여하지 않는다. 치명타율은 개인 스킬 전용.

**티어별 예시**:

| 티어 | HIT | PDR | 예시 |
|------|-----|-----|------|
| T1 (가죽) | +1% | 100% | 가죽 장갑, 사냥꾼의 장갑 |
| T2 (사슬) | +1% | 99% | 사슬 장갑, 철제 건틀릿 |
| T3 (판금) | +2% | 97% | 판금 건틀릿, 풀 건틀릿 |

#### RMMZ Studio 기본 설정 (armorType 12 공통)

| 항목 | 설정 |
|------|------|
| HIT 보정 | +1% (특성 → xparam → 명중률 +0.01) — 기준값 |
| PDR 보정 | 99% (특성 → sparam → 물리 데미지율 99%) — 기준값 |
| 노트태그 | `<armorSlot:gloves>` |

## 5. 장신구 (armorType 7~9) — 참고 사항

장신구는 고정 프리셋 없이 개별 아이템마다 고유 효과를 부여한다.

| armorType | 유형 | 주로 부여하는 효과 계열 |
|-----------|------|---------------------|
| 7 | 반지 | 원소 내성, 상태이상 내성, 특수 발동 효과 |
| 8 | 목걸이 | MDF 보정, MDR 감소, 상태이상 내성 |
| 9 | 팔찌 | ATK/DEF/AGI 소폭 보정, HIT/EVA 미세 보정 |

> 장신구는 이 사양서의 범위 밖. 개별 아이템 설계 시 반영.

## 6. 노트태그 요약

### 방어구 노트태그

| 태그 | 적용 대상 | 효과 |
|------|----------|------|
| `<armorClass:cloth>` | 의복 (armorType 1) | 곡도 curved 판정 시 "경장" 취급 (×1.5 피해) |
| `<armorClass:light>` | 경갑 (armorType 2) | 곡도 curved 판정 시 "경장" 취급 (×1.5 피해) |
| `<armorClass:heavy>` | 중갑 (armorType 3) | 곡도 ×0.7 / heavyRanged ×1.5 판정 대상 |
| `<magicSeal:true>` | 중갑 (armorType 3) | **마법 스킬 사용 불가** (물리 스킬은 가능) |
| `<movePenalty:N>` | 중갑 (armorType 3) | 이동력 -N |
| `<shieldBlock:N>` | 방패 (armorType 4~6) | GRD 발동 시 피해 N% 감소 (50/60/70) |
| `<armorSlot:helm>` | 투구 (armorType 10) | 부위 식별. CEV 로직 연동 |
| `<armorSlot:boots>` | 신발 (armorType 11) | 부위 식별. 이동력 관련 SRPG 로직 연동 |
| `<armorSlot:gloves>` | 장갑 (armorType 12) | 부위 식별. HIT 보정 로직 연동 |

### 무기 측 연동 태그 (무기 사양서에서 정의됨, 참고용)

| 태그 | 효과 | 방어구 측 판정 |
|------|------|-------------|
| `<weaponRole:curved>` | 곡도. 경장 ×1.5, 중갑 ×0.7 | armorClass cloth/light → ×1.5, heavy → ×0.7 |
| `<weaponRole:axe>` | 도끼. 파괴 가능 사물 ×2.0 | srpgObject 판정 (방어구 무관) |
| `<heavyRanged:true>` | 중쇠뇌/장궁. 중갑 ×1.5 | armorClass heavy → ×1.5 |

## 8. 방어력 종합 — 풀셋 착용 시 예상 수치

> 동일 티어 T2 기준, 몸통 + 방패 + 투구 + 신발 + 장갑 풀셋 시 합산 보정.
> DEF/MDF 기본 수치는 개별 아이템 파라미터로 별도.

### 8.1 중갑 탱커 풀셋 (중갑 + 대형 방패 + 판금 부위)

| 스탯 | 합산 보정 | 산출 |
|------|----------|------|
| EVA | -14% | 중갑-5 + 대형방패-5 + 투구-3 + 신발-1 + 장갑0 |
| PDR | ~70% | 중갑78 × 투구95 × 신발98 × 장갑97 (곱연산 ≈ 0.70) |
| MDR | 100% | 기본값 유지 |
| GRD | 35% | 대형 방패 |
| CEV | +5% | 판금 투구 |
| 타격 내성 | 150% | 중갑 |
| 이동력 | -1 | 중갑 패널티 |
| 마법 | **불가** | 중갑 magicSeal |

**의미**: 물리 ~30% 감소 + 35% 확률 70% 차단. 회피 거의 불가. 마법 사용 불가. 둔기·마법이 천적.

### 8.2 경갑 유격 풀셋 (경갑 + 중형 방패 + 사슬 부위)

| 스탯 | 합산 보정 | 산출 |
|------|----------|------|
| EVA | -1% | 경갑0 + 중형방패0 + 투구-2 + 신발+1 + 장갑0 |
| PDR | ~87% | 경갑92 × 투구96 × 신발99 × 장갑99 (곱연산 ≈ 0.87) |
| MDR | 100% | 기본값 유지 |
| GRD | 25% | 중형 방패 |
| CEV | +3% | 사슬 투구 |
| 이동력 | 0 | 패널티 없음 |
| 마법 | 가능 | |

**의미**: 물리 ~13% 감소 + 25% 확률 60% 차단. 기동성 유지. 범용 균형 빌드.

### 8.3 의복 마법사 풀셋 (의복 + 소형 방패 + 가죽 부위)

| 스탯 | 합산 보정 | 산출 |
|------|----------|------|
| EVA | +4% | 의복0 + 소형방패+3 + 투구-1 + 신발+2 + 장갑0 |
| PDR | ~98% | 의복100 × 투구98 × 신발100 × 장갑100 (곱연산 ≈ 0.98) |
| MDR | 100% | 기본값 유지 |
| GRD | 15% | 소형 방패 |
| CEV | +2% | 가죽 투구 |
| 이동력 | 0 | 패널티 없음 |
| 마법 | 가능 | |

**의미**: 물리 피해 거의 기준. 가죽 부위의 미세 감소만. 방패 패링으로 가끔 생존. 마법 자유.

### 8.4 의복 마법사 — 방패 없음 (양손 스태프 사용)

| 스탯 | 합산 보정 | 산출 |

| EVA | +1% | 의복0 + 투구-1 + 신발+2 + 장갑0 |
| PDR | ~98% | 의복100 × 투구98 × 신발100 × 장갑100 (곱연산 ≈ 0.98) |
| MDR | 100% | 기본값 유지 |
| GRD | 0% | 방패 없음 |
| 이동력 | 0 | 패널티 없음 |
| 마법 | 가능 | |

**의미**: 방어 거의 전무. 후방 배치 필수. 양손 무기의 화력·사거리로 보상.
