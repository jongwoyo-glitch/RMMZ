# 모험가 파티 시스템 설계서

**버전:** v0.1 (초안)
**작성일:** 2026-04-29
**상태:** 설계 논의 완료 — 구현 전

---

## 1. 설계 철학

### 핵심 원칙
- RMMZ 타일맵은 **SRPG 전투 전용**. 비전투 파트는 스탠딩 일러스트 기반 시뮬레이션.
- "회의"는 단체 행동 전후의 **준필수 Phase**로, 인물 상호작용 기회를 극대화.
- 오행 원국은 **백엔드 엔진**이지, 플레이어가 학습해야 할 UI가 아님.
- 전통 RPG 플레이어에게 익숙한 판타지 용어로 표면을 구성하고, 사주는 내적 논리로 작동.

### 게임 루프
```
거점 → [회의 Phase] → 행동 실행(전투/탐색/의뢰) → 결과 · 피드백 → [분배 회의] → 거점
         ↑                                                              │
         └────────────── 관계 변화 · 성장 · 자금 정책 ─────────────────┘
```

## 2. 캐릭터 정보 3층 구조

### 2-A. 인물 개요 — "이 사람이 누구인가"
- 이름, 스탠딩 일러스트, 원국 8자 테이블
- 가호 시스템에서 도출된 성격 특성, 신살, 아키타입
- 유대 관계 요약 (주요 인물과의 인상·유대 태그)

### 2-B. 전투 정보 — "이 사람이 얼마나 싸울 수 있는가"
- RMMZ 네이티브 전투 스탯: HP, MP, ATK, DEF, MAT, MDF, AGI, LUK
- 전투 오각형 (주요 전투 능력 레이더 차트)
- 장비, 스킬 목록, SRPG 전용 속성 (이동력, 사거리, 사격 모드)
- 클래스·레벨로 성장, 장비로 보정 — **훈련과 경험의 결과**

### 2-C. 성향 정보 — "이 사람은 어떤 성격인가"
- 원국에서 도출된 오행 성향 프로필 (가호 시스템 용어로 표현)
- 다섯 원형(전사/성직자/마법사/도적/바드) 관점의 성향 서술
- 파티 내 기능 배치 시 적성의 근거가 되는 정보
- **수치가 아닌 서술어로 표현** — "타고난 길잡이", "불꽃 같은 입담" 등

> **설계 의도:** 전투 스탯 = "뭘 할 수 있는가" (성장 가능), 성향 = "어떤 사람인가" (원국에서 도출, 거의 고정). 이 이원화로 ATK 같은 전사 둘이 파티 내에서 전혀 다른 역할을 할 수 있음.

## 3. 능력치 이원화

### 전투 능력치
- **출처:** RMMZ 네이티브 (클래스 파라미터 + 레벨 + 장비)
- **용도:** SRPG 전투에서의 데미지, 명중, 회피, HP 등
- **성장:** 레벨업, 장비 교체, 스킬 습득으로 변화
- **표시:** 전투 오각형 + 수치 목록

### 오행 성향 (파티 적성)
- **출처:** 원국 8자에서 GahoSystem이 도출
- **용도:** 파티 기능 태그 배치 시 효율 결정, 회의 시 의견 성향, AI 성향
- **성장:** 거의 고정 (원국은 타고난 것). 경험에 의한 미세 보정은 가능.
- **표시:** 가호 시스템 용어의 서술어. 파티 구성 UI에서는 태그 색조(빨강→노랑→초록)로 적성 표현.

## 4. 파티 시스템

### 4-A. 구조

#### Game_AdventureParty (신규 클래스)
- `$gameParty`를 직접 수정하지 않고 **래핑하여 확장**
- 편성 변경 시 내부적으로 `$gameParty.addActor/removeActor` 호출
- 기존 SRPG 파티 슬롯, MenuOverhaul과 자동 호환

```
$gameAdventureParty
  ├── leaderActorId        // 파티장
  ├── members[]            // {actorId, functionTags[], slotIndex}
  ├── presets[]             // 저장된 편성 세트
  ├── partyMorale           // 사기 (수치 자원)
  ├── actionPoints          // 행동력 (수치 자원)
  ├── partyFund             // 공유 자금
  ├── fundPolicy            // {shareRatio, distMethod, bonusRule}
  ├── personalWealth[]      // 멤버별 개인 재산 {actorId, amount}
  └── → $gameParty (동기화) // RMMZ 네이티브 호환
```

#### 파티장
- **회의 주재:** 의제 설정, 최종 결정(채택/기각)
- **파티 관리:** 멤버 영입/해고, 기능 태그 배정, 프리셋 관리
- **전투:** 작전 수립 주도, 역할 배정, 배치 위치 결정
- **갈등 중재:** 별도 기능 모듈이 아닌 파티장 고유 권한

#### 플레이어 시점에 따른 경험 차이
- **소속 멤버일 때:** NPC 파티장이 결정. 플레이어는 의견 제시만 가능. 성장하면 영향력↑
- **파티장일 때:** 플레이어가 전권 보유. 멤버 의견을 듣고 채택/무시 선택.
- **성장 곡선:** 신입(발언권 낮음) → 핵심 멤버(가중치↑) → 독립(자기 파티 결성) → 파티장(전권)

### 4-B. 기능 태그 시스템

#### 5대 원형에서 추출한 기능 영역

D&D 고전 5인 파티 원형(전사·성직자·마법사·도적·바드)에서 비전투 기능을 모듈화.
각 기능 태그는 해당 원형의 오행 적성이 있으며, 배치된 캐릭터의 원국 성향에 따라 태그 색조가 변함.

| 원형 | 오행 | 기능 영역 | 비전투 담당 | 전투 연계 |
|------|------|-----------|------------|-----------|
| 전사 | 土 | 수호 (Guardian) | 야영 경비, 물리 장애물, 호위, 방어 진지 | 전열 유지, 탱킹 |
| 성직자 | 水 | 치유 (Healer) | 부상 치료, 해독, 정신 케어, 갈등 완화 | 회복, 정화, 버프 |
| 마법사 | 金 | 해석 (Analyst) | 아이템 감정, 고문서, 지식 조회, 위험 분석 | 정밀 타격, 제어 |
| 도적 | 木 | 탐사 (Explorer) | 정찰, 함정 대응, 잠입, 선행 수색, 추적 | 급소 공격, 기동 |
| 바드 | 火 | 연결 (Liaison) | 교섭, 정보 수집, 사기 관리, 대외 대표 | 고무, 교란 |

#### 태그 배치 규칙
- 파티 구성 UI에서 파티원 앞에 기능 태그를 **하나하나 붙이는** 방식
- 한 사람이 여러 태그를 겸임 가능 (효율 분산)
- 태그 색조가 적성에 따라 자동 변화: **빨강**(부적합) → **노랑**(보통) → **초록**(적합)
- 적성은 원국 오행 성향에서 자동 도출 (플레이어에게는 색조로만 보임)

#### 파티 규모 스케일링
- **1인:** 혼자 다 하지만, 몇몇 기능은 비활성화 (회의 불가, 교섭 제한 등)
- **2~3인:** 기본 기능 커버 가능. 음식 대충 먹어도 됨.
- **4~5인:** 기능 요구 레벨 상승. 요리사/병참 없으면 식량 소모 비효율, 사기 하락.
- **6인 이상:** 전문화 태그 필수. 의료, 정비, 교섭 등 빈 기능이 직접적 패널티로 작용.
- → 파티 인원 상한이 하드 리밋이 아니라, **기능 커버리지에 의한 소프트 게이트**

### 4-C. 파티 구성 UI (메인 메뉴 별도 진입)

#### 구성 요소
1. **파티원 목록** — 현재 파티 구성원 + 파티장 표시
2. **기능 태그 패널** — 각 파티원에 배치된 태그 목록 (색조 표시)
3. **로스터** — 영입 가능한 인원 목록 + 성향 요약
4. **프리셋** — 저장된 편성 세트 (태그 배치 포함)
5. **파티 상태** — 사기, 행동력, 공유 자금, 보급 상황 요약
6. **자금 정책 패널** — 현재 정책 요약 (공유 비율, 분배 방식, 특별 수입 규칙)

#### 기존 MenuOverhaul과의 관계
- MenuOverhaul의 전술 탭은 **전투 관련 전술 정보** 유지
- 파티 구성 UI는 **별도 메뉴 항목**으로 독립
- 두 UI 모두 `$gameAdventureParty`를 참조하되, 관심사가 다름

## 5. 자원 체계

### 수치 기반 자원 (파티 전체 상태값) — 2종

#### 사기 (Morale)
- 파티 전체의 정신적 상태
- **상승 요인:** 승리, 좋은 식사, 충분한 휴식, 바드/연결 기능, 회의에서 갈등 해결
- **하락 요인:** 패배, 식량 부족, 갈등 방치, 열악한 야영, 부상 방치
- **효과:** 전투 시 공격/방어 보정, 회의에서 협조도, 극단적 저하 시 강한 디버프
- **연결 기능(火)** 담당자 적성에 따라 사기 유지/회복 효율 변동

#### 행동력 (Action Points)
- 파티가 단체 행동 전후로 **준비 작업**에 쓰는 자원
- **용도:** 회의 개최, 척후 파견, 사전 정보 수집, 야영 준비, 정비 시간 확보
- **회복:** 거점 체류, 휴식, 특정 이벤트
- **전략적 의미:** 준비를 많이 하면 유리하지만 행동력 소모 ↔ 즉시 행동은 리스크 있지만 행동력 절약

### 아이템 기반 자원 (그리드 인벤토리에 실물로 존재) — 3종

#### 식량 아이템
- 파티 인원 비례 소모
- 요리(Cook) 태그 담당자 → 소비 효율 개선, 음식 버프 제공
- 병참(Quartermaster) 태그 담당자 → 낭비 감소, 보급 계획 최적화
- 부족 시 → 사기 하락, 장기 시 HP 회복 불가

#### 자재 아이템
- 장비 수리, 야영 설비, 함정 설치 등에 사용
- 정비(Tinker)/대장장이(Smith) 태그 담당자 → 자재 소비 효율 향상
- 부족 시 → 장비 내구도 회복 불가, 야영 품질 저하

#### 재료 아이템
- 약초, 연금술 재료, 포션 원료 등
- 약초(Herbalist)/연금술(Alchemist) 태그 담당자 → 채집 효율, 조제 성공률
- 부족 시 → 회복 아이템 제작 불가

> **장비 내구도:** 별도 수치 자원이 아닌 개별 장비의 내구도 속성. 자재 아이템을 소비하여 정비. 정비 태그 담당자가 있으면 효율적, 없으면 마을에서 비싼 비용으로 수리.

### 파티 자금 관리

#### 개요
파티 자금은 식량·자재·재료와 달리 **정책적 선택**이 개입하는 자원. 어떻게 벌고, 어떻게 나누느냐가 파티 내 관계 드라마의 핵심 촉매.

#### 자금 구조
- **공유 자금 (Party Fund):** 파티 공금. 보급품 구매, 숙박, 수리, 의뢰 경비 등 파티 운영비에 사용.
- **개인 재산 (Personal Wealth):** 각 멤버의 사적 자산. 개인 장비 구매, 사적 거래, 저축에 사용.
- **비율:** 수입의 몇 %가 공유 자금으로 가고 나머지가 개인 분배되는지는 **자금 정책**으로 결정.

#### 자금 정책 (회의 안건)

자금 정책은 파티 회의에서 결정하며, 변경 시에도 회의가 필요. 아래 세 축의 조합으로 정책이 구성됨.

**축 1 — 공유 비율 (파티 운영비 적립)**
- 수입에서 먼저 공유 자금으로 떼어놓는 비율 설정 (예: 30%, 50%, 70%)
- 높을수록 파티 안정 ↑, 개인 불만 ↑
- 낮을수록 개인 만족 ↑, 비상시 자금 부족 리스크 ↑

**축 2 — 개인 분배 방식 (나머지를 어떻게 나눌 것인가)**

| 방식 | 설명 | 유리한 성향 |
|------|------|------------|
| 균등 분배 | 머리 수로 나눔 | 土 — 안정·공평 중시 |
| 기여도 비례 | 전투 기여, 의뢰 달성도 반영 | 金 — 논리·효율 중시 |
| 역할별 차등 | 위험 담당(전열)에게 더 많이 | 水 — 형평·배려 중시 |
| 필요 기반 | 장비 수리·소모품 필요에 따라 | 木 — 실용·유연 중시 |
| 자유 재량 | 파티장이 재량 분배 | 火 — 신뢰·유대 중시 |

**축 3 — 특별 수입 처리 (보너스·보물 등)**
- 발견자 우선권: 발견한 사람에게 우선 취득 기회
- 파티 경매: 파티 내 경매 → 수익은 공유 자금으로
- 공유 자산화: 무조건 공유 자금에 편입
- → 이 역시 회의에서 결정, 성향에 따라 의견 충돌

#### 의뢰 보수 교섭
- 의뢰 수락 시 보수 협상 가능 — **교섭(Negotiator, 火+水)** 태그 담당자가 수행
- 적성 높은 교섭 담당자 → 보수 상향 협상 성공률 ↑, 추가 조건 확보
- 적성 낮거나 미배치 → 기본 보수만 수령, 불리한 조건 수용 리스크
- 교섭 결과도 회의에서 보고 → "이걸 수락할지" 의견 개진 → 드라마 발생

#### 오행 성향별 자금 의견 (회의 연동)

자금 정책이 회의 안건에 올라올 때, 각 멤버의 원국 성향이 자동으로 의견 성향을 생성:

| 오행 우세 | 자금 관련 성향 | 전형적 발언 |
|-----------|---------------|------------|
| 木 | 실용주의 — 필요에 따라 유연하게 | "지금 당장 수리비가 급하니 먼저 쓰고 보자" |
| 火 | 관계 중심 — 신뢰가 돈보다 중요 | "돈 문제로 사이 틀어지면 끝이야" |
| 土 | 공평 중시 — 똑같이 나눠야 | "머리 수대로 나누는 게 제일 공정하지" |
| 金 | 효율 추구 — 기여한 만큼 가져가야 | "노력 안 한 놈이랑 같은 몫이면 말이 되나" |
| 水 | 배려 지향 — 약자에게 더 줘야 | "장비가 망가진 사람부터 챙기는 게 맞아" |

- 상극 관계의 두 멤버가 자금 문제로 대립 → 인상 변동, 유대 태그 변화
- 예: 金우세 + 土우세 = "기여도 비례" vs "균등 분배" 충돌 (土克水가 아닌 **의견 차이** 기반)
- 파티장의 결정이 특정 멤버의 의견과 일치/불일치 → 순종도에 반영

#### 자금 관련 이벤트
- **자금 고갈:** 숙박 불가, 보급품 구매 불가, 긴급 회의 자동 트리거
- **큰 수입:** 보물 발견, 대형 의뢰 완수 → 분배 회의 자동 트리거
- **불화 누적:** 분배 불만 3회 이상 → 멤버 탈퇴 위기 이벤트
- **착복 의혹:** 병참/교섭 담당자의 낮은 인상 + 자금 감소 → 의심 이벤트
- **월급날:** 정기 분배 시점마다 미니 회의 (빠른 처리 모드)

#### 게임 루프에 미치는 영향
```
의뢰 수주 → [교섭] → 보수 결정
                         ↓
                   [회의: 수락 여부]
                         ↓
                   행동 실행 (전투/탐색)
                         ↓
                   수입 발생
                         ↓
                   [회의: 분배 결정] ← 자금 정책 적용
                         ↓
              공유 자금 적립 + 개인 분배
                    ↓              ↓
            파티 운영비 충당    개인 만족/불만
                                    ↓
                          관계 변화 → 다음 회의에 영향
```

> **설계 의도:** 자금은 단순한 숫자가 아니라 **가치관 충돌의 매개체**. "얼마"가 아니라 "어떻게 나누느냐"가 드라마의 핵심. 모든 자금 결정이 회의를 경유하므로 매번 인물 간 마찰과 유대가 갱신되며, 이것이 전투 순종도로 직결됨.

## 6. 회의 시스템

### 트리거
- **단체 행동 전후**의 준필수 Phase
- 출진 전, 의뢰 수락 후, 던전 중 긴급 상황, 귀환 후 보고, 파티 편성 변경 시
- 배경만 교체 (야영지, 주점, 던전, 길드) — 시스템은 동일

### 내부 Phase (범용 구조)

#### Phase 1 — 상황 공유
- 회의 배경 연출 + 참석자 스탠딩 배치
- 의제 제시 (무엇에 대해 논의할 것인가)
- 각 기능 태그 담당자가 자기 영역 보고

#### Phase 2 — 의견 개진 (핵심)
- 각 파티원이 원국 성향에 따라 의견 제시
- 상극 시 대립, 상생 시 보완
- 파티장/리더 여부에 따라 발언 순서·가중치 차등
- 관계 태그(유대·인상)가 동조/반발에 영향
- **여기서 인물 드라마 발생** — 감정 변화, 유대 태그 갱신

#### Phase 3 — 결정/채택
- 파티장(또는 플레이어)이 최종 선택
- 반대 의견 수용/무시 가능
- 무시당한 멤버 인상↓, 수용된 멤버 인상↑

#### Phase 4 — 행동 전환 (분기)
- **4a. 전투 회의:** SRPG 맵 미리보기 + 배치·역할 지정 → AI 프리셋
- **4b. 비전투 회의:** 역할 분담·준비 사항 확인 → 행동 실행

### 행동력 소비
- 회의 개최 자체가 행동력을 소비
- "회의를 한 번 더 할까 vs 바로 돌입할까" = 전략적 선택

### 원국 기반 의견 생성

#### 상극 (克) — 방향성 대립
- 둘 다 논리적이지만 관점이 다름
- 예: 木克土 → "돌격하자" vs "진지 구축"

#### 충 (衝) — 격렬한 반발
- 같은 축의 정반대 지지
- 인상 변동 큼, 유대 태그 영향

#### 형 (刑) — 스트레스성 마찰
- 비난이 아닌 "불편한 지적"
- 무드 하락, 장기적 관계 영향

#### 중재 (合·삼합·방합)
- 제3자가 대립을 조율
- 파티장 또는 합 관계 인물이 수행

### 기존 자산 활용
- `GahoSystem.getCombatTendency()` → 의견 성향 도출
- 관계 시스템 인상/유대 API → 의견 채택 결과 반영
- `SRPG_CombatAI.js` 오행 가중치 → 회의 결정 오버라이드 레이어

## 7. 전투 연계

### 작전 프리셋 (전투 역할)
- 파티 기능 태그(비전투)와 **별도로** 전투 역할을 지정
- 전투 회의(Phase 4a)에서 결정
- 역할 → CombatAI 가중치 오버라이드

### 순종도 메카닉 (불복종)
- 회의에서 의견이 채택된 멤버 → 높은 순종도 → 작전대로 행동
- 회의에서 무시당한 멤버 → 낮은 순종도 → AI가 독단 행동 가능
- 원국 상극 + 낮은 인상 = 불복종 확률 최대
- **"작전대로 안 움직이는 동료" = 관계 관리 실패의 기계적 결과**

### SRPG 파티 슬롯과의 연동
- `_resolvePartySlots()`에서 `$gameAdventureParty`의 멤버 순서 참조
- 역할(작전 프리셋) 정보를 SrpgUnit에 전달
- 전투 AI가 역할 + 순종도를 기반으로 행동 결정
