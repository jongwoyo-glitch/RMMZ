# 무기·방어구 티어 설계서

> 보편(베이스) 무기 3단계 티어 + 유니크(창작명) 구조 설계.
> 티어 원칙: **유럽권/대중 인지도 높음 → T1(일반)**, 중간 인지도 → T2(정예), **비유럽권/생소 → T3(희귀)**.
> 유니크 무기는 전부 세계관 고유 창작명으로 별도 설계한다.
> 참조 게임: 디아블로2, 엘든링, 마비노기, 소울류, 마운트앤블레이드2: 배너로드
> 작성일: 2026-05-01

---

## 설계 원칙

| 등급 | 코드 | 느낌 | 입수 시점 | 이름 특성 |
|------|------|------|-----------|-----------|
| **T1 일반** | Common | 양산형, 흔한 군용 | 초반~중반 초 | 누구나 아는 유럽식 이름 |
| **T2 정예** | Uncommon | 장인 제작, 정예 무장 | 중반 | 게이머·역사 팬이 아는 이름 |
| **T3 희귀** | Rare | 이국적, 전문적 | 중후반 | 생소한 비유럽·고대 이름 |
| **유니크** | Unique | 전설·유물급 | 후반/이벤트 | 세계관 고유 창작명 |

- T1→T2→T3는 같은 무기 타입 내 수직 성장. 무기의 전술적 성격(사거리, 공격 방식)은 유지.
- 모든 무기 타입에 T1~T3를 강제하지 않음. 특수군(마법 무기 등)은 T1~T2만으로 충분.
- 유니크는 티어 외 별도 트랙. T3급 스탯 + 고유 특수 효과.
