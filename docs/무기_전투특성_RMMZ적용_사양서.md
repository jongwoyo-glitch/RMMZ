## 2. 근접 무기 4군 — 역할 변별 사양

### 2.1 기본 원칙

직검 = ×1.0 기준. 특장점 = ×1.5, 약점 = ×0.7.

| 무기군 | 공격 원소 | 경장 배율 | 중갑 배율 | 엄폐물 배율 |
|--------|----------|----------|----------|-----------|
| 직검 | 절단(13) | ×1.0 | ×1.0 | ×1.0 |
| 곡도 | 절단(13) | **×1.5** | **×0.7** | ×1.0 |
| 둔기 | 타격(11) | ×1.0 | **×1.5** | ×1.0 |
| 도끼 | 절단(13) | ×1.0 | ×1.0 | **×2.0** |

### 2.2 구현 방법

**둔기 vs 중갑**: 원소 시스템으로 처리 가능.
- 둔기 무기: 공격 원소 = 타격(11)
- 중갑 방어구: 원소 내성(Element Rate) → 타격(11) = 150% (피해 1.5배 받음)
- 이것만으로 둔기 vs 중갑 ×1.5 성립

**곡도 vs 경장/중갑, 도끼 vs 엄폐물**: 원소만으로 분리 불가 (직검과 같은 절단 원소).
→ **노트태그 + 플러그인으로 처리**.

```
[곡도 무기 노트태그]
<weaponRole:curved>

[도끼 무기 노트태그]
<weaponRole:axe>

[직검 무기 — 태그 불필요 (기본값)]
```

플러그인이 전투 시 weaponRole을 읽고:
- curved → 대상 armorType 1(의복),2(경갑) 시 데미지 ×1.5 / armorType 3(중갑) 시 ×0.7
- axe → 대상이 srpgObject(파괴 가능 사물) 시 데미지 ×2.0

## 6. 중갑 원소 내성 — 방어구 측 설정

> 둔기·중쇠뇌·장궁의 중갑 강세를 원소 시스템으로 처리하기 위한 방어구 측 설정.
> RMMZ Studio: 방어구 편집 → 특성 → 속성 유효도(Element Rate)

| 방어구 유형 | 타격(11) Rate | 관통(12) Rate | 절단(13) Rate |
|-----------|-------------|-------------|-------------|
| 의복 (armorType 1) | 100% | 100% | 100% |
| 경갑 (armorType 2) | 100% | 100% | 100% |
| 중갑 (armorType 3) | **150%** | 100% | 100% |

- 의복·경갑은 기준(100%). 원소에 의한 추가 피해 없음.
- 중갑은 타격(11)에 150%. → 둔기·권갑 계열 자동으로 ×1.5.
- 곡도 vs 경장, 도끼 vs 엄폐물은 원소로 처리 불가 → weaponRole 노트태그+플러그인.

**중쇠뇌·장궁의 중갑 관통 (×1.5)**:
- 이것은 관통(12) 원소의 중갑 Rate를 올리면 경량 원거리까지 혜택 받으므로 부적합.
- → `<heavyRanged:true>` 노트태그 + 플러그인에서 중갑 상대 시 ×1.5 ���용.

## 7. 노트태그 요약

### 무기 노트태그

| 태그 | 적용 대상 | 효과 |
|------|----------|------|
| `<weaponRole:curved>` | 곡도 전체(3,7,11) | 의복·경갑 ×1.5 / 중갑 ×0.7 |
| `<weaponRole:axe>` | 도끼 전체(4,8,12) | 파괴 가능 사물 ×2.0 |
| `<moveAndShoot:true>` | 손쇠뇌(17), 경쇠뇌(18), 단궁(20) | 이동 후 사격 가능 |
| `<moveAndShoot:false>` | 중쇠뇌(19), 장궁(21) | 이동 후 사격 불가 (기본) |
| `<heavyRanged:true>` | 중쇠뇌(19), 장궁(21) | 중갑 상대 ×1.5 (고관통) |

### 방어구 트레잇 (RMMZ 네이티브)

| 방어구 유형 | 설정할 특성 |
|-----------|-----------|
| 중갑 (armorType 3) | 속성 유효도 → 타격(11) = 150% |
